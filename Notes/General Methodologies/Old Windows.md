
The SAM & the SYSTEM File are stored in the System32 directory. But since this is an backup before an update, the SAM & SYSTEM Files aren't getting blocked by Windows itself and we can access them within the directory.
## Default Paths

```
C:\Windows\System32\config\SAM
C:\Windows\System32\config\SYSTEM
```

```
C:\Windows\System32\SAM
C:\Windows\System32\SYSTEM
```
